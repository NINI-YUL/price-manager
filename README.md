# 多渠道本地化价格管理工具

文档版本：V0.4（Phase1 核心功能完成基线）
更新时间：2026-08-19

## 项目简介

本项目是一款 Windows 本地桌面工具，用于导入 Google Play、iOS App Store 和三方网页支付价格文件，将各渠道数据标准化为“渠道 + 国家/地区 + USD 档位 + 币种 + 本地价格”，并提供校验、查询、版本归档能力。

## 当前结论

- 技术基线：Python 3.11+、PySide6、SQLite、openpyxl、pytest。
- 当前阶段：P1-001～P1-009 已完成，Phase1 核心功能闭环完成；Phase2 尚未确认。
- 本阶段只完成三渠道导入、标准化、检查、价格库和版本管理。
- 汇率分析、调价任务、修改校验、渠道 API 和更多渠道不属于 Phase1。

## 客户端启动与独立验收

- 正式客户端：在项目目录运行 `.\.venv\Scripts\python.exe -m src.main`。
- Phase1 独立验收客户端：直接双击根目录的 `启动Phase1验收环境.cmd`。
- 验收窗口标题会显示“Phase1 独立验收环境”，数据写入 `acceptance_runtime/`，不会影响正式数据库和归档。
- 完整验收步骤见 `docs/04_测试验收/02_Phase1客户端验收指南.md`。

## 开发启动门槛

P1-001～P1-009 及 Phase1 客户端验收整改已完成并验收。三渠道均支持后台解析、统一检查、完整快照确认、正式版本事务、来源归档、只读价格库与版本管理；数据库为 schema v4。历史版本可经二次确认原子启用，状态变化全程审计，归档来源可核验。Phase2 和价格导出尚未确认，不自动设计或编码。

## Phase1 客户端验收整改

- 主导航已固定为左侧导航；导入检查使用左侧“解析详情”、右侧“解析问题（错误/警告）”的 70:30 可拖动布局。
- 解析详情同时展示国家码和中文国家/地区名；iOS 调价方式显示“手动调价/自动调价”；问题说明中文化并保留代码和来源定位。
- 本地价格按“整数不显示小数、非整数显示两位、超过两位有效小数保留原值并提示”展示。
- Google 2,422 条和 iOS 2,450 条真实样本档位筛选已降至约 21～35ms；当前自动化基线为 115 项。
- 完整规则和验收记录见 `docs/03_开发设计/21_Phase1客户端验收整改执行说明.md`。
