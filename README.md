# 多渠道本地化价格管理工具

文档版本：V0.5（Phase1 + Phase2 验收基线）
更新时间：2026-08-21

## 项目简介

本项目是一款 Windows 本地桌面工具，用于导入 Google Play、iOS App Store 和三方网页支付价格文件，将各渠道数据标准化为“渠道 + 国家/地区 + USD 档位 + 币种 + 本地价格”，并提供校验、查询、版本归档与只读汇率偏差分析能力。

## 当前结论

- 技术基线：Python 3.11+、PySide6、SQLite、openpyxl、pytest。
- 当前阶段：Phase1 已于 2026-08-19 正式通过客户端验收；Phase2 汇率分析已于 2026-08-21 正式通过客户端验收。
- 已完成三渠道导入、标准化、检查、价格库、版本管理，以及独立汇率快照驱动的只读偏差分析。
- Phase3 调价与修改校验、价格导出、渠道 API 和更多渠道尚未授权，不自动设计或编码。

## 开发启动门槛

Phase1 与 Phase2 均已完成并验收。三渠道支持后台解析、统一检查、完整快照确认、正式版本事务、来源归档、只读价格库与版本管理；代码数据库基线为 schema v5。汇率分析只写独立的汇率快照与获取日志，既有价格、版本和状态保持只读。当前没有已授权的后续开发任务；Phase3 和价格导出不得自动设计或编码。

## Phase1 客户端验收整改

- 主导航已固定为左侧导航；导入检查使用左侧“解析详情”、右侧“解析问题（错误/警告）”的 70:30 可拖动布局。
- 解析详情同时展示国家码和中文国家/地区名；iOS 调价方式显示“手动调价/自动调价”；问题说明中文化并保留代码和来源定位。
- 本地价格按“整数不显示小数、非整数显示两位、超过两位有效小数保留原值并提示”展示。
- Google 2,422 条和 iOS 2,450 条真实样本档位筛选已降至约 21～35ms；当前自动化基线为 115 项。
- 完整规则和验收记录见 `docs/03_开发设计/21_Phase1客户端验收整改执行说明.md`。

## Phase2 正式验收结论

- 负责人已于 2026-08-21 完成客户端验收并确认 Phase2 通过；当前自动化基线为 157 项测试、Ruff 与双客户端 Qt 冒烟通过。
- 汇率主源为 ExchangeRate-API 免费开放接口，方向固定为 `1 USD = X 本地币种`；按价格记录自身币种计算，不经中间币种。
- 汇率快照不可变并永久保留，自动与手动获取共用去重规则；分析结果动态计算，不反写七张 Phase1 表。
- 详细业务规则、实现边界和验收索引以 `docs/03_开发设计/22_Phase2汇率分析执行说明.md` 为唯一执行基线。
