# 多渠道本地化价格管理工具

文档版本：V0.3（Phase1 开发启动基线）  
更新时间：2026-08-17

## 项目简介

本项目是一款 Windows 本地桌面工具，用于导入 Google Play、iOS App Store 和三方网页支付价格文件，将各渠道数据标准化为“渠道 + 国家/地区 + USD 档位 + 币种 + 本地价格”，并提供校验、查询、版本归档能力。

## 当前结论

- 技术基线：Python 3.11+、PySide6、SQLite、openpyxl、pytest。
- 当前阶段：Phase1 已开始开发；P1-001～P1-003 已完成，下一任务为 P1-004。
- 本阶段只完成三渠道导入、标准化、检查、价格库和版本管理。
- 汇率分析、调价任务、修改校验、渠道 API 和更多渠道不属于 Phase1。
