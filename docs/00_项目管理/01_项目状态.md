## 已确认

- 渠道：Google Play、iOS App Store、三方网页支付。
- 核心模型：渠道、国家编码、USD 档位、币种、本地价格、版本。
- 技术：Python + PySide6 + SQLite + Excel 解析。
- 表：`countries`、`price_tiers`、`channel_products`、`channel_prices`、`price_versions`、`import_tasks`、`version_status_events`（schema v4）。
- 导入流程：上传 → 解析 → 校验 → 用户确认 → 生成版本 → 写入价格库 → 归档原文件。
- 14 个 USD 档位与 Google 实际宽表结构已经业务确认。
- iOS 的 14 个档位目录、两类 CSV、逐行 N/Y 调价方式和 191 个国家/地区并集已经业务确认。
- Web 的两行表头、国家 `价格/收入` 列对、表头权威币种、积分档位、收入与颜色忽略规则已经业务确认。
- P1-008 已确认只读价格库、档位/国家两种视角、各渠道独立活动/历史版本选择、按导入时间年月分组与搜索、缺价显示、居中价格格式和本阶段不导出。
- P1-009 已确认历史版本原子启用、schema v4 状态审计、来源归档检查、详情/价格库联动、不删除版本和不提供价格导出。
- 已提供独立 Phase1 客户端验收环境，数据库、归档和导出写入 cceptance_runtime/，不影响正式运行数据。
