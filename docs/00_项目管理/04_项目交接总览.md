## 关键规则

- 渠道范围：Google Play、iOS App Store、三方网页支付。
- 核心模型：渠道、国家编码、USD 档位、币种、本地价格、版本。
- 技术：Python 3.11+、PySide6、SQLite、openpyxl、pytest、Ruff。
- 正式价格必须经过解析、校验和用户确认后才写入。
- 国家代码采用两个大写字母；币种采用三个大写字母。
- 金额用 `Decimal`；数据库使用 NUMERIC。
- 基础数据显示名固定来自 Unicode CLDR 48.2.0，范围与默认币种来自 Google 样本。
- 一次只推进一个已确认任务；发现规则缺失时先提问。

完整决策见 `docs/00_项目管理/03_设计决策记录.md`，完整业务规则见 `docs/01_产品设计/02_业务规则说明.md`。

## 新环境恢复命令

同一台电脑可直接打开 `E:\项目管理\渠道价格管理工具`。换电脑时先用 GitHub Desktop 或普通 Git 克隆仓库，然后在 PowerShell 执行：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m src.database.seed
$env:QT_QPA_PLATFORM = "offscreen"
.\.venv\Scripts\python.exe -m src.main --smoke-test
```

如果 pytest 对系统临时目录报“拒绝访问”，使用项目 `data/` 下的唯一临时目录：

```powershell
$handoffTemp = Join-Path $PWD ("data\pytest-handoff-" + [guid]::NewGuid().ToString("N"))
.\.venv\Scripts\python.exe -m pytest --basetemp $handoffTemp
```
