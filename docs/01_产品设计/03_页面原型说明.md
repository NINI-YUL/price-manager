# 页面原型说明

## 1. 首页/导航

入口：价格导入、导入任务、价格库、版本管理、基础数据。顶部显示当前活动版本与最近导入结果。

## 2. 价格导入

- 渠道单选、文件选择、开始解析。
- 展示文件名、大小、摘要、解析进度。
- 解析完成后进入检查页，不直接入库。

## 3. 导入检查

- 摘要：国家数、档位数、价格数、错误数、警告数。
- 问题表：级别、Sheet、行、列、原值、说明、建议。
- 数据预览可按国家、档位、问题状态筛选。
- 有阻断错误时禁用“确认入库”；无阻断错误时允许生成版本。

P1-007 已实现价格导入与检查合并页：三渠道文件/目录选择、后台解析、摘要、问题与价格表、国家/档位/问题筛选、警告/覆盖缩减二次确认和成功版本提示。导航、价格库与版本管理页面仍按后续任务补充。

## 4. 价格库

- 档位视角：选择 USD 档位，行是国家，列是渠道。
- 国家视角：选择国家，展示全部档位与渠道价格。
- 支持渠道、币种和版本筛选；默认活动版本。

## 5. 版本管理

展示版本号、渠道、导入时间、来源文件、记录数、状态；支持查看详情，不允许直接编辑历史版本。

## 交互原则

耗时解析进入后台任务；危险操作二次确认；错误信息使用业务语言并保留技术详情供排查。
