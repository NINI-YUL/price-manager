# 业务规则说明

## 统一记录

一条价格记录表示：某渠道、某国家/地区、某 USD 档位、某币种在某版本中的本地价格。

## 标识与金额

- `channel` 枚举：`GOOGLE`、`IOS`、`WEB`。
- `country_code`：大写 ISO alpha-2；未知值不可自动写正式库。
- `currency`：大写 ISO 4217 三字码。
- `usd_tier` 与 `local_price`：正数 Decimal；不得用 float 做相等判断。
- `adjustment_mode`：iOS 记录使用 `MANUAL` 或 `AUTOMATIC`，分别来自原始字段 `N`、`Y`；Google/Web 记录可为空。
- 同一版本内 `(channel, country_code, usd_tier, currency)` 唯一。

## 导入规则

- 原始单元格允许首尾空白，标准化时去除；不得改变有意义的商品 ID。
- 空价格、非数字、负数、未知国家、未知档位、重复且值冲突均为阻断错误。
- 完全相同的重复行可去重并给出警告。
- 国家别名只有在唯一映射时可自动匹配，并记录警告。
- 同渠道同国家同档位出现多个币种时默认阻断，除非后续业务规则明确允许。
- iOS 以每行 `货币代码` 为价格记录权威币种，国家表的 `default_currency` 不覆盖它；`收入` 字段不参与本阶段价格模型。
- iOS 国家中文名先匹配 CLDR 显示名，再匹配独立的已批准别名配置；未知或歧义名称阻断。
- Web 识别两行表头：A 列 `积分` 直接映射 14 个 USD 档位，每个国家由 `价格/收入` 两列组成；只读取价格，忽略收入和全部单元格样式/颜色。
- Web 顶层 `国家或地区(币种)` 中的币种为该记录权威币种，不要求等于国家默认币种；文件可只包含基础国家范围的子集，但所有出现国家必须唯一映射。
- Web 国家中文名先匹配 CLDR 显示名，再匹配独立的已批准别名；当前别名为 `捷克共和国→CZ`。

## 版本规则

- 格式：`{CHANNEL}_VYYYYMMDD_NNN`，序号按渠道与日期递增。
- 同一渠道只能有一个 `ACTIVE` 版本；新版本激活与旧版本归档必须处于同一事务。
- 导入失败不得创建活动版本；原始文件摘要用于追溯和重复提示。
- 所有 ERROR 阻断入库；WARNING 可经二次确认继续。检查页不修改预览价格，错误必须回到来源修正后重新解析。
- 每次确认都是该渠道的完整快照，不合并旧活动版本；国家数或记录数较旧版本减少时必须强提醒并再次确认。
- 同渠道、相同来源摘要已生成正式版本时禁止重复入库；未成功的任务允许重试。
- 正式版本必须先完成来源复制归档：Google/Web 保留原 `.xlsx`，iOS 目录打包 ZIP；不得移动或修改原来源。
- 历史 `ARCHIVED` 版本可在二次确认后重新启用；当前 `ACTIVE` 版本归档、目标版本激活和状态事件必须在同一事务中完成。
- 版本状态只允许 `ACTIVE`、`ARCHIVED`；不允许单独归档当前活动版本，不允许删除正式历史版本。
- 导入确认、手动启用和 schema v4 迁移基线均写入版本状态审计；手动备注可选，最多 200 字。
- Google/Web 归档使用 SHA-256 校验；iOS ZIP 只校验 ZIP 完整性，原始目录摘要不与 ZIP 文件摘要直接比较。
- 归档异常只警告、不阻止数据库价格快照启用；任何归档越界路径均拒绝访问。

## 客户端展示规则

- USD 档位统一显示两位小数。
- 本地价格数值为整数时显示整数；有一位或两位有效小数时显示两位；超过两位有效小数时保留原值并提示核对，不静默舍入。
- 展示格式不改变数据库 Decimal 原值，不参与计算、换算或相等判断。
- 导入详情必须同时展示国家码与中文国家/地区名；iOS `MANUAL/AUTOMATIC` 分别显示“手动调价/自动调价”。
- 错误/警告以中文说明为主，同时保留稳定问题代码、Sheet/文件、行、列和原值；ERROR/WARNING 级别和 P1-007 门禁不因翻译改变。

## Phase2 汇率分析规则

- 汇率主源为 ExchangeRate-API 免费开放接口；基准币种固定为 USD，方向固定为 `1 USD = X 本地币种`，按价格记录自身币种换算且不经过中间币种。
- 每个供应商更新时间最多保存一个不可变成功快照；成功快照永久保留，重复快照不入库，失败日志保留 90 天并按需清理。
- 工具关闭时不获取；运行期间按供应商下一更新时间自动获取，并提供手动获取按钮。自动与手动请求共用快照去重和缓存策略。
- 默认使用各渠道活动版本，允许只读选择历史版本；每个渠道独立选择一个完整价格版本，一次分析统一绑定一个汇率快照。历史选择不改变版本状态或审计。
- 理论本地价格为 `USD 档位 × API 汇率`；偏差率为 `(实际本地价格 - 理论本地价格) / 理论本地价格 × 100%`。绝对偏差小于 10% 为正常，10%（含）至 20% 为关注，20%（含）以上为显著偏差。
- API 汇率最多显示 3 位小数；金额与计算使用 Decimal。Phase2 只允许新增/读取独立汇率快照和获取日志，分析结果动态计算，不反写价格库。
- 详细异常语义、展示规则、UI 状态和验收边界以 `docs/03_开发设计/22_Phase2汇率分析执行说明.md` 为唯一执行基线。
