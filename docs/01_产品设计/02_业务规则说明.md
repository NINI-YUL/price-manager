# 业务规则说明

## 统一记录

一条价格记录表示：某渠道、某国家/地区、某 USD 档位、某币种在某版本中的本地价格。

## 标识与金额

- `channel` 枚举：`GOOGLE`、`IOS`、`WEB`。
- `country_code`：大写 ISO alpha-2；未知值不可自动写正式库。
- `currency`：大写 ISO 4217 三字码。
- `usd_tier` 与 `local_price`：正数 Decimal；不得用 float 做相等判断。
- 同一版本内 `(channel, country_code, usd_tier, currency)` 唯一。

## 导入规则

- 原始单元格允许首尾空白，标准化时去除；不得改变有意义的商品 ID。
- 空价格、非数字、负数、未知国家、未知档位、重复且值冲突均为阻断错误。
- 完全相同的重复行可去重并给出警告。
- 国家别名只有在唯一映射时可自动匹配，并记录警告。
- 同渠道同国家同档位出现多个币种时默认阻断，除非后续业务规则明确允许。

## 版本规则

- 格式：`{CHANNEL}_VYYYYMMDD_NNN`，序号按渠道与日期递增。
- 同一渠道只能有一个 `ACTIVE` 版本；新版本激活与旧版本归档必须处于同一事务。
- 导入失败不得创建活动版本；原始文件摘要用于追溯和重复提示。
