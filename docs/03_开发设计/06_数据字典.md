# 数据字典

## countries

|字段|类型|约束|
|---|---|---|
|id|INTEGER|PK|
|country_code|TEXT|UNIQUE, NOT NULL, 长度2|
|name_cn|TEXT|NOT NULL|
|name_en|TEXT|NOT NULL|
|default_currency|TEXT|NOT NULL, 长度3|

## price_tiers

`id INTEGER PK`；`usd_price NUMERIC NOT NULL UNIQUE CHECK(usd_price>0)`。

## channel_products

`id INTEGER PK`；`channel TEXT NOT NULL`；`product_id TEXT NOT NULL`；`usd_tier NUMERIC NOT NULL`；唯一键 `(channel, product_id)`；`usd_tier` 外键关联 `price_tiers.usd_price`。

## price_versions

`id INTEGER PK`；`version_id TEXT UNIQUE NOT NULL`；`channel TEXT NOT NULL CHECK(channel IN ('GOOGLE','IOS','WEB'))`；`source_file TEXT NOT NULL`；`source_sha256 TEXT`；`import_time TEXT NOT NULL`；`status TEXT NOT NULL CHECK(status IN ('ACTIVE','ARCHIVED'))`；`record_count INTEGER NOT NULL DEFAULT 0 CHECK(record_count>=0)`；组合唯一键 `(version_id, channel)` 用于约束价格版本所属渠道。

## channel_prices

`id INTEGER PK`；`channel TEXT NOT NULL CHECK(channel IN ('GOOGLE','IOS','WEB'))`；`country_code TEXT NOT NULL`；`usd_tier NUMERIC NOT NULL`；`currency TEXT NOT NULL`；`local_price NUMERIC NOT NULL CHECK(local_price>0)`；`adjustment_mode TEXT NULL CHECK(adjustment_mode IS NULL OR adjustment_mode IN ('MANUAL','AUTOMATIC'))`；`version_id TEXT NOT NULL`；`created_time TEXT NOT NULL`；唯一键 `(version_id, channel, country_code, usd_tier, currency)`；国家、档位为外键，`(version_id, channel)` 组合外键确保价格渠道与版本渠道一致。

## import_tasks

`id INTEGER PK`；`task_id TEXT UNIQUE NOT NULL`；`channel TEXT NOT NULL CHECK(channel IN ('GOOGLE','IOS','WEB'))`；`file_path TEXT NOT NULL`；`status TEXT NOT NULL CHECK(status IN ('PROCESSING','CHECKING','SUCCESS','FAILED'))`；`error_count INTEGER NOT NULL DEFAULT 0 CHECK(error_count>=0)`；`warning_count INTEGER NOT NULL DEFAULT 0 CHECK(warning_count>=0)`；`created_time TEXT NOT NULL`；`completed_time TEXT`；`error_message TEXT`；`version_id TEXT NULL` 外键关联 `price_versions.version_id`，非空时唯一。

## version_status_events

`id INTEGER PK`；`event_id TEXT UNIQUE NOT NULL`；`version_id TEXT NOT NULL`；`channel TEXT NOT NULL`；`from_status TEXT NULL`；`to_status TEXT NOT NULL`；`replaced_version_id TEXT NULL`；`reason TEXT NOT NULL CHECK(reason IN ('IMPORT_CONFIRMATION','MANUAL_ACTIVATION','MIGRATION_BASELINE'))`；`note TEXT NULL CHECK(length(note)<=200)`；`actor TEXT NOT NULL`；`created_time TEXT NOT NULL`。`(version_id,channel)` 组合外键关联版本，`replaced_version_id` 也受版本外键约束。

## 通用约定

当前 schema 版本为 4；旧版数据库启动时在同一事务中补充既有字段、状态事件表和迁移基线，失败整体回滚。时间采用带时区 ISO 8601 文本；SQLite 每个连接启用 `PRAGMA foreign_keys=ON`。索引覆盖价格查询、版本来源摘要、任务状态和状态事件时间线；部分唯一索引保证每个渠道最多一个 `ACTIVE` 版本、一个正式版本最多关联一个任务。
