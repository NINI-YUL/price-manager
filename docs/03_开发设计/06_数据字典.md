# 数据字典

## countries

|字段|类型|约束|
|---|---|---|
|id|INTEGER|PK|
|country_code|TEXT|UNIQUE, NOT NULL, 长度2|
|name_cn|TEXT|NOT NULL|
|name_en|TEXT|NOT NULL|
|default_currency|TEXT|NOT NULL, 长度3|

## price_tiers

`id INTEGER PK`；`usd_price NUMERIC NOT NULL UNIQUE CHECK(usd_price>0)`。

## channel_products

`id INTEGER PK`；`channel TEXT NOT NULL`；`product_id TEXT NOT NULL`；`usd_tier NUMERIC NOT NULL`；唯一键 `(channel, product_id)`；`usd_tier` 外键关联 `price_tiers.usd_price`。

## price_versions

`id INTEGER PK`；`version_id TEXT UNIQUE NOT NULL`；`channel TEXT NOT NULL`；`source_file TEXT NOT NULL`；`source_sha256 TEXT`；`import_time TEXT NOT NULL`；`status TEXT NOT NULL CHECK(status IN ('ACTIVE','ARCHIVED'))`；`record_count INTEGER NOT NULL DEFAULT 0`。

## channel_prices

`id INTEGER PK`；`channel TEXT NOT NULL`；`country_code TEXT NOT NULL`；`usd_tier NUMERIC NOT NULL`；`currency TEXT NOT NULL`；`local_price NUMERIC NOT NULL CHECK(local_price>0)`；`version_id TEXT NOT NULL`；`created_time TEXT NOT NULL`；唯一键 `(version_id, channel, country_code, usd_tier, currency)`；国家、档位、版本为外键。

## import_tasks

`id INTEGER PK`；`task_id TEXT UNIQUE NOT NULL`；`channel TEXT NOT NULL`；`file_path TEXT NOT NULL`；`status TEXT NOT NULL CHECK(status IN ('PROCESSING','CHECKING','SUCCESS','FAILED'))`；`error_count INTEGER NOT NULL DEFAULT 0`；`warning_count INTEGER NOT NULL DEFAULT 0`；`created_time TEXT NOT NULL`；`completed_time TEXT`；`error_message TEXT`。

## 通用约定

时间采用带时区 ISO 8601 文本；SQLite 启用 `PRAGMA foreign_keys=ON`。建议索引：价格表的 `(channel,country_code,usd_tier)` 与 `version_id`，任务表的 `status,created_time`。
