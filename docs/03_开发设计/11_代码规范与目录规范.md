# 代码规范与目录规范

## 推荐目录

```text
src/
├── main.py
├── config/
├── ui/
├── models/
├── database/
├── services/
├── adapters/
└── utils/
tests/{unit,integration,fixtures}/
data/  archives/  exports/  docs/
```

## 代码规则

- UTF-8、4 空格、类型标注；模块/函数用 `snake_case`，类用 `PascalCase`，常量大写。
- 业务金额使用 `Decimal`；数据库参数化查询，禁止字符串拼 SQL。
- 函数单一职责；UI 不写 SQL，Repository 不解析 Excel。
- 捕获异常时保留上下文并转换为明确的业务错误，禁止空 `except`。
- 路径使用 `pathlib.Path`，配置集中管理，不硬编码用户绝对路径。

## 测试与提交

新增规则必须有正常、边界和失败用例。测试不得依赖真实用户文件或执行顺序。提交应围绕单一任务，说明行为变化与验证结果。
