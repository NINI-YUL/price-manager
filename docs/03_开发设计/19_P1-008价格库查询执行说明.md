# P1-008 价格库查询执行说明

版本：V1.0｜确认日期：2026-08-17｜状态：规则已确认，待负责人明确开始编码

## 目标与边界

在 P1-007 已生成的正式价格版本之上，提供只读价格库查询页面，让用户按 USD 档位或国家/地区比较 Google、iOS 和三方网页价格，并可选择各渠道活动版本或历史版本。

本任务包含主导航接入、价格库 Repository/查询服务、两种查询视角、筛选、分组版本选择器、只读详情、刷新、空状态和自动化测试。

本任务不包含：

- 编辑、删除或补写正式价格。
- 激活、归档或删除价格版本；这些属于 P1-009。
- 导出价格库文件。
- 汇率折算、价格偏差、调价建议或渠道 API。
- 绕过 P1-007 确认服务直接写入 `channel_prices`、`price_versions` 或 `import_tasks`。

P1-008 不要求修改 schema v3；正式数据库查询必须只读。

## 页面入口

- 主窗口增加“价格导入”和“价格库”入口，价格导入继续使用 P1-007 已有页面。
- 进入价格库时默认打开“按档位查看”。
- 页面提供手动刷新；P1-007 成功确认新版本后，价格库刷新并将对应渠道切换到新活动版本。
- P1-008 不在价格库页面提供编辑、删除、激活或归档按钮。

## 渠道版本选择

Google、iOS、三方网页分别使用独立版本选择器：

1. 默认选择各渠道当前 `ACTIVE` 版本。
2. 当前活动版本固定置顶，只显示一次，不在历史月份中重复。
3. 历史版本依据 `price_versions.import_time` 按“年 → 月”分组；年份、月份和月内版本均按时间倒序。
4. 默认展开当前年份及最近月份，其余年月折叠。
5. 支持按版本号、来源文件名和导入日期搜索。
6. 选择器主显示包含版本号、状态和导入日期；选项同时显示来源文件。
7. 允许选择 `ARCHIVED` 历史版本做只读跨渠道比较，不允许在本页改变版本状态。
8. 某渠道没有正式版本时显示“无版本”，该渠道列继续保留并显示缺价。
9. 手动刷新后，若原选择仍存在则保持；若已不可用则回到该渠道活动版本，无活动版本则显示“无版本”。

## 按档位查看

- 默认视角。
- 从已确认的 14 个 USD 档位中选择一个档位。
- 行为所选渠道版本中出现过的国家/地区并集。
- 列依次为国家/地区、国家编码及当前启用的 Google、iOS、三方网页渠道。
- 默认按国家编码升序；最多 191 行，本阶段不分页。
- 可启用“显示全部 191 个国家/地区”，将未出现在所选版本中的基础国家也列出并显示缺价。
- iOS 价格旁显示“手动”或“自动”调价标识，对应 `MANUAL`/`AUTOMATIC`；Google/Web 不显示该标识。

## 按国家查看

- 可从全部 191 个基础国家/地区中选择，支持按国家编码、中文名和英文名搜索。
- 行固定为全部 14 个 USD 档位，按数值升序。
- 渠道列与档位视角一致，并显示 iOS 调价方式。
- 某渠道、国家或档位没有价格时显示缺价，不从其他版本或其他渠道补值。

## 筛选与重置

- 渠道多选，默认 Google、iOS、三方网页全部启用。
- 币种筛选默认“全部币种”；选定币种后，保留至少一个已选渠道价格使用该币种的行，同时继续展示该行所有已选渠道单元格，便于横向比较。
- 档位视角支持国家编码、中文名和英文名搜索。
- 国家视角支持 USD 档位搜索。
- “重置筛选”恢复默认活动版本、档位视角、USD 9.99、全部渠道、全部币种、空搜索条件和未勾选“显示全部国家/地区”。
- 筛选只影响展示，不修改正式价格或版本。

## 展示格式

- 所有表头居中对齐。
- Google、iOS、三方网页价格单元格居中对齐；缺价符号也居中。
- 国家/地区名称正文左对齐，国家编码居中。
- 本地价格与币种在同一单元格连续显示，例如 `1500 JPY`、`9.99 USD`，不得拆成独立币种列。
- USD 档位固定显示两位小数。
- 本地价格保持数据库中的十进制精度，不执行汇率转换、自动取整或额外四舍五入，不使用科学计数法，也不添加千位分隔符。
- 缺失价格统一显示 `—`，不得显示为 `0`，也不得沿用其他版本价格。

## 只读详情

点击已有价格可查看只读详情：

- 渠道、所选版本号与版本状态。
- 国家/地区和国家编码。
- USD 档位、本地价格及币种。
- iOS 调价方式；Google/Web 显示为空。
- 版本导入时间与价格记录创建时间。

详情不提供修改或删除入口。Google 商品 ID 不作为 P1-008 每条国家价格的必显字段，避免把档位级商品映射误解为国家级价格属性。

## 空状态与异常状态

- 三个渠道都没有正式版本：显示“尚无正式价格，请先在价格导入页完成确认入库”，并提供返回价格导入页的操作。
- 单一渠道没有版本：保留该渠道列，列内显示“无版本”或 `—`，不影响其他渠道查询。
- 部分国家或档位缺价：仅对应单元格显示 `—`。
- 筛选无结果：显示“没有符合当前筛选的数据”。
- 查询失败：显示业务化错误提示并保留“重试/刷新”，不得把异常数据展示为有效价格。

## 查询与性能要求

- UI 不直接拼接 SQL；通过 Repository 与查询服务读取 `countries`、`price_tiers`、`price_versions` 和 `channel_prices`。
- 查询金额继续使用 `Decimal` 语义，不转为二进制浮点数参与业务格式化。
- 每次刷新重新读取数据库，不依赖跨会话缓存。
- 当前规模为每版本最多约 191 × 14 条，档位视角最多 191 行、国家视角固定 14 行；本阶段不分页。
- 历史版本选择必须按导入时间分组和排序，不从版本号字符串猜测年月。

## 导出边界

P1-008 不提供价格库导出。导出格式、版本组合、缺价语义和渠道用途应在 P1-009 完成后另行确认，不得在实现中预留未经确认的业务按钮。

## 自动化测试

Repository/服务测试至少覆盖：

- 各渠道活动版本默认选择和历史版本查询。
- 三渠道独立版本组合，不发生跨版本串数。
- 档位视角国家并集、显示全部基础国家和国家编码排序。
- 国家视角固定 14 档及档位排序。
- 渠道、币种、国家和档位筛选及重置。
- Web 部分国家覆盖、单元格缺价、单渠道无版本和全部无版本。
- iOS `MANUAL`/`AUTOMATIC` 展示。
- 版本按 `import_time` 年月分组、倒序、活动版本置顶、搜索与选中保持。
- Decimal 精度、两位 USD 档位、无科学计数法和无千位分隔符。

UI 测试至少覆盖：

- 主导航进入价格库，默认档位视角。
- 两种视角切换及表头/价格居中展示。
- 三个分组版本选择器的展开、年月折叠、搜索、历史版本选择和无版本状态。
- 渠道/币种/搜索/全部国家筛选和重置。
- 点击价格打开只读详情。
- 手动刷新和 P1-007 确认成功后的自动刷新。
- 无版本、部分缺价、无筛选结果及查询失败提示。

## 验收方式

1. 使用临时数据库建立 Google、iOS、Web 活动版本和至少一个历史版本，不向正式数据库写测试价格。
2. 验证档位视角、国家视角、独立版本组合、缺价和 iOS 调价方式与数据库一致。
3. 验证版本数量增多时仍可按年月折叠和搜索，不出现重复活动版本。
4. 验证成功确认新价格版本后，对应渠道刷新到新活动版本，其他渠道选择不被重置。
5. 运行全量 `pytest`、Ruff 和 Qt 无界面启动测试；记录实际测试数量和结果。
