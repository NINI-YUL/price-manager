# P1-004 Google 价格导入执行说明

状态：已完成｜完成日期：2026-08-17

## 目标与边界

实现 Google Excel 到标准价格记录与问题列表的解析能力。P1-004 只产生预览结果，不创建正式价格版本；确认入库属于 P1-007/P1-009。

## 输入契约

- 首版支持 `.xlsx`，拒绝加密、损坏或超出配置大小的文件。
- 不硬编码列号；通过规范化表头和别名配置识别商品 ID、国家代码、币种及价格列。
- 已确认模板为单 Sheet 宽表：A～C 列依次为 `国家/地区`、`国家代码`、`货币类型`，D～Q 为 14 个商品列。
- 商品列完整标题作为 `product_id`，价格单元格为当地价格文本；必须用 Decimal 解析。
- `国家/地区` 列在当前样本中全部为 `17`，首版忽略该列，以 `国家代码` 和 `货币类型` 为准。

## 档位识别

优先查 `channel_products` 的 `(GOOGLE, product_id)` 映射。无映射时，按已确认规则提取 `_iap_` 后、`&` 后缀前的数值，例如 `com.163.vg.vk_iap_9.99&legacy-base → 9.99`；同时兼容没有 `&` 后缀的标题。提取值必须使用 Decimal 且存在于 `price_tiers`。成功后可在确认流程中建议新增映射，不在解析阶段静默改库。

建议正则：`_iap_(\d+(?:\.\d{1,2})?)(?:&[^\s]*)?$`。不得从商品 ID 中任意数字猜档位，也不得丢弃完整 product_id 的后缀。

## 已确认样本画像

- 文件：`google价格_get_result.xlsx`（仅本地参考，不提交 Git）。
- 工作表：`Sheet1`；范围：`A1:Q174`。
- 数据：173 个唯一国家代码、61 种币种、14 个档位、2,422 个价格。
- 当前样本无空值、无重复国家代码、无非法国家/币种格式，价格均可解析且大于 0。
- 自动测试必须从该结构制作脱敏最小 fixture，并保留 `&legacy-base` 后缀场景。

## 标准化流程

1. 校验文件并建立 `PROCESSING` 任务。
2. 选择含必需表头的工作表；无法唯一识别时报错。
3. 忽略 A 列常量值；读取国家代码与币种并转大写，校验基础数据。
4. 对每个商品价格单元格解析 Decimal；空白视为缺失，不转为 0。
5. 产生 `StandardPrice`，保存 Sheet/行/列位置。
6. 检查重复键、冲突值、档位覆盖率与同国家多币种。
7. 输出统计和问题，将任务置为 `CHECKING`；解析异常置为 `FAILED`。

## 错误码

|错误码|级别|含义|
|---|---|---|
|G001|ERROR|文件无法读取或格式不支持|
|G002|ERROR|缺少/重复必需表头|
|G003|ERROR|商品 ID 无法映射档位|
|G004|ERROR|国家未知或格式非法|
|G005|ERROR|币种未知或格式非法|
|G006|ERROR|价格空缺、非数字或不大于0|
|G007|ERROR|同一标准键出现冲突价格|
|G008|ERROR|缺少已配置的必需档位列|
|G101|WARNING|国家别名被唯一自动匹配|
|G102|WARNING|完全相同重复记录已去重|
