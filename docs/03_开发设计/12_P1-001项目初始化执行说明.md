# P1-001 项目初始化执行说明

## 目标

建立可启动、可测试、符合分层规范的 Python 项目骨架。本任务不建立业务表、不解析 Excel、不开发业务页面。

## 执行

1. 建立 `src` 分层目录、运行目录和 `tests`。
2. 创建包标识、`src/main.py` 与最小 PySide6 窗口/启动逻辑。
3. 创建集中配置，声明项目名、版本与运行路径。
4. 创建 `requirements.txt`、`.gitignore` 和测试配置。
5. 添加启动冒烟测试，确保导入模块不产生数据库副作用。

## 验收

- `python -m src.main` 可启动并正常退出。
- `python -m pytest` 通过。
- 运行目录不存在时能安全创建。
- Git 忽略 `.venv/`、`__pycache__/`、数据库、日志、归档和导出文件。
- 没有 Google/iOS/Web 业务代码和未经确认的数据表。

完成后更新项目状态，等待进入 P1-002。
