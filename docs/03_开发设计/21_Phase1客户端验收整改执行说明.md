# Phase1 客户端验收整改执行说明

版本：V1.1｜日期：2026-08-19｜状态：已完成

## 一、整改目标

根据 Phase1 独立客户端首次人工验收反馈，完善导航结构、导入检查信息、中文业务表达、金额展示和大数据量筛选性能，使 Phase1 可以继续通过独立 Windows 客户端验收。

本次不修改数据库 schema、三渠道解析规则、正式入库事务、版本状态规则或归档根目录；不进入 Phase2，也不进行完整主题、配色、图标和品牌视觉重构。

## 二、已确认并实现的界面规则

1. 主导航固定在左侧，依次为“价格导入”“价格库”“版本管理”；右侧显示当前业务页面。
2. 导入检查区左侧为“解析详情”，右侧为“解析问题（错误/警告）”，默认比例 70:30，支持拖动分隔条。
3. 解析详情左侧保留从 1 开始的连续行号，同时展示“国家码”和“国家/地区”中文名；筛选器显示 `国家码｜中文名`，筛选后行号按当前结果重新连续编号。
4. iOS 原始 `N/Y` 仍分别存为 `MANUAL/AUTOMATIC`，界面统一显示“手动调价/自动调价”。
5. 无解析问题时右侧显示“本次解析无异常”；应用筛选后无结果时显示“当前筛选条件下无问题”。
6. 问题级别和说明使用中文，但保留稳定问题代码、Sheet/文件、行、列及原值，便于定位与技术排查。
7. 来源无法解析等未预期异常显示通用代码 `SYS001` 和中文业务提示；底层技术异常不直接替代业务说明。

## 三、金额展示规则

- USD 档位固定显示两位小数。
- 本地价格若数值为整数，显示整数，例如 `1500.00 → 1500`。
- 本地价格若有一位或两位有效小数，统一显示两位，例如 `1.5 → 1.50`、`1.25 → 1.25`。
- 若未来出现超过两位有效小数的合法价格，界面保留原值并显示核对提示，不静默舍入。
- 价格继续使用 `Decimal`；展示格式不改变数据库原值，也不用于价格换算。
- 价格库表头和价格保持居中，币种紧跟价格显示。

## 四、问题中文对照

- Google：`G001～G008`、`G101/G102`。
- iOS：`I001～I008`、`I102`。
- Web：`W001～W008`、`W102`。
- 确认入库：`C001～C008`。
- 系统级解析异常：`SYS001`。

代码是稳定排障标识；中文说明是用户主读信息。错误继续阻断确认入库，警告继续遵循 P1-007 二次确认规则，本次整改不改变严重级别和门禁。

## 五、性能实现

解析继续在后台线程执行。解析详情由逐单元格创建 `QTableWidgetItem` 改为 `QAbstractTableModel + QSortFilterProxyModel + QTableView`：

- 预览记录只在新解析结果到达时重置一次；
- 国家/档位切换只改变代理模型过滤条件，不重建数千个单元格对象；
- 列宽使用固定初始宽度并允许人工拖动，不再对全部数据执行 `ResizeToContents`。

真实样本只读性能验证：

|渠道|记录数|初次展示|切换到 1.99 档|恢复全部|
|---|---:|---:|---:|---:|
|Google|2,422|21.83ms|35.40ms|19.69ms|
|iOS|2,450|21.52ms|21.47ms|19.45ms|

以上为 2026-08-19 当前开发机器的离屏客户端测量，只用于验证筛选路径不再出现分钟级无响应，不作为不同电脑上的硬性绝对耗时承诺。

## 六、验收要求

- 左侧导航与三个 Phase1 页面可正常切换。
- Google/iOS 真实样本解析后，国家码、中文国家名、金额和 iOS 调价方式符合本说明。
- 切换国家或档位时界面保持可响应，不重建来源模型。
- 问题说明中文可读，并保留代码和来源定位；无问题时显示正确空状态。
- 价格导入确认、价格库、版本管理和独立验收数据隔离均无回归。
- 全量自动化测试、Ruff、正式客户端与独立验收客户端 Qt 冒烟全部通过。

## 七、本次明确不做

- 不提供归档根目录变更；归档仍使用工具当前运行根目录下的固定运行路径。
- 不删除或自动清理已有归档文件；手工删除归档只会导致版本来源校验显示缺失，不删除数据库价格版本。
- 不进行完整 UI 主题、颜色、图标、动画与品牌视觉优化。
- 不开发汇率分析、调价建议、价格导出、渠道 API 或 Phase2/Phase3 功能。
