# 开发环境准备说明

## 环境

- Windows 10/11、Git、Python 3.11 或 3.12。
- 创建项目虚拟环境：`python -m venv .venv`，激活后安装 `requirements.txt`。
- 建议依赖：PySide6、openpyxl、pytest、pytest-cov、ruff。

## 首次检查

```powershell
python --version
python -m pip install -r requirements.txt
python -m pytest
python -m src.main
```

## 数据目录

`data/`、`archives/`、`exports/` 为运行目录。数据库、业务 Excel、日志与导出物不得提交 Git；仅提交脱敏测试样本。

## 故障排查

确认命令使用虚拟环境 Python；检查工作目录与配置路径；SQLite 锁定时确认没有重复进程；Excel 失败时先记录扩展名、Sheet 和表头，不直接改业务规则。
