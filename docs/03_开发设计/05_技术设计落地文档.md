# 技术设计落地文档

## 技术栈

- Python 3.11+；PySide6；SQLite 3。
- openpyxl 读取 `.xlsx`；pytest 测试；标准库 `decimal` 处理金额。
- Phase1 不要求服务端和外部数据库。

## 分层

`ui` 只负责交互；`services` 编排用例与事务；`adapters` 解析渠道文件；`models` 定义领域对象；`database` 负责 schema/repository；`utils` 放无业务状态的公共能力。

## 导入契约

Adapter 输入为文件路径与导入上下文，输出 `ParseResult(records, issues, metadata)`。标准记录至少包含 `channel、country_code、usd_tier、currency、local_price、source_location`。

## 事务边界

解析阶段不写 `channel_prices`。确认时在单一事务内创建版本、写价格、归档旧活动版本、完成任务；任一步失败全部回滚。

## 配置与日志

数据库和目录路径集中配置；表头别名与国家别名可配置。日志不得记录完整敏感文件内容，需包含 task_id、阶段、耗时和异常堆栈。
