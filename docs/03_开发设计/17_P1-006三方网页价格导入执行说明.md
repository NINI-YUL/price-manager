# P1-006 三方网页价格导入执行说明

版本：V1.0｜完成日期：2026-08-17｜状态：已完成

## 目标与边界

将已确认的三方网页 `.xlsx` 宽表只读解析为统一 `StandardPrice` 预览、问题列表和统计，并记录 `import_tasks` 生命周期。P1-006 不创建正式价格版本，不写入 `channel_prices` 或 `price_versions`；用户确认和正式入库属于 P1-007 及后续任务。

## 已确认输入结构

- 工作簿内必须且只能有一个符合结构的工作表，工作表名称不写死。
- 数据区域使用两行表头；A 列为 `积分`，其余列按国家成对出现。
- 每个国家顶层表头为 `国家或地区(币种)`，同时兼容半角和全角括号。
- 国家列第二行必须依次为 `价格`、`收入`。
- A 列 14 行积分直接映射 `usd_tier`，必须完整覆盖已配置的 14 个档位。
- `价格` 映射 `local_price`；`收入` 在 P1-006 忽略，即使未来出现非空值也不进入价格模型。
- 顶层表头中的币种是该网页价格的权威币种，不要求等于国家表的 `default_currency`。
- 单元格颜色、字体、边框和其他样式均无业务意义并全部忽略，包括样本中的黄色填充。
- 网页渠道可以只覆盖基础国家表的子集，但文件中出现的每个国家都必须唯一映射到现有国家代码。
- Web 没有商品 ID 和自动调价字段，`product_id`、`adjustment_mode` 均为 `None`。

## 标准字段映射

|原始位置|标准字段|规则|
|---|---|---|
|A 列 `积分`|`usd_tier`|使用 `Decimal`，必须属于 14 个已配置档位|
|顶层 `国家或地区(币种)`|`country_code`|CLDR 中文名优先，其次匹配已批准 Web 别名|
|顶层括号内容|`currency`|三个大写字母，且必须属于当前支持币种|
|子列 `价格`|`local_price`|使用 `Decimal`，必须大于 0|
|子列 `收入`|无|忽略|
|无对应字段|`channel`|固定为 `WEB`|
|无对应字段|`product_id`、`adjustment_mode`|固定为 `None`|

当前 Web 独立别名为 `捷克共和国→CZ`。别名文件在服务启动预览前校验表头、重复值和目标国家代码，不修改原工作簿或国家种子。

## 解析和校验流程

1. 检查输入为存在的 `.xlsx` 文件且不超过 50 MB，计算 SHA-256。
2. 以只读模式分别读取公式值和公式文本；修复模板声明维度异常后识别唯一结构匹配工作表。
3. 校验两行表头和所有国家列对，解析国家及权威币种。
4. 逐行解析档位和价格，忽略收入与所有样式，生成标准记录和源单元格定位。
5. 校验国家、币种、档位、正数价格、重复与冲突、14 档完整性。
6. 创建导入任务并按结果置为 `CHECKING` 或 `FAILED`；不执行正式价格或版本写入。

## 问题代码

|代码|级别|含义|
|---|---|---|
|W001|错误|文件不存在、类型不支持、超限或无法读取|
|W002|错误|找不到唯一结构匹配工作表，或两行表头/国家列对非法|
|W003|错误|国家名称未知、歧义或未配置|
|W004|错误|币种格式非法或不受支持|
|W005|错误|档位为空、非法、存在公式但无缓存值，或不属于配置档位|
|W006|错误|价格为空、非法、非正数，或存在公式但无缓存值|
|W007|错误|重复国家列、相同标准键数据冲突或同国家同档位多币种|
|W008|错误|未完整覆盖 14 个配置档位|
|W102|警告|完全相同记录重复，保留一条并提示去重|

文件/结构类错误会使预览任务进入 `FAILED`；数据类问题保留可检查预览并进入 `CHECKING`。P1-007 再定义用户确认门禁和正式事务。

## 真实样本回归

样本 `标准价格配置表 (1).xlsx` 只读回归结果：

- SHA-256：`28c70d60126e4df2facd2759af271a7006c1a9d47e60f071c9fc3c7155fd9a38`。
- 唯一结构工作表：`输出表`，实际区域 `A1:BI16`。
- 14 个档位、30 个国家/地区、20 种币种、420 条价格。
- 420 个收入单元格均为空；解析器无论是否为空都忽略该列。
- 420 个价格均有效，国家/地区全部映射成功，错误、警告、重复和冲突均为 0。
- 乌克兰表头币种为 USD，与国家默认 UAH 不同，按已确认规则保留 USD。
- 黄色填充单元格未影响数值解析；回归前后源文件哈希一致。
- 正式 `channel_prices`、`price_versions` 均保持 0 条。

真实样本只记录结构、摘要和统计，不复制到 Git；自动测试使用运行时生成的最小脱敏工作簿。
