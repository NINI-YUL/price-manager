# 测试验收标准

## 测试层级

- 单元：金额、编码、表头、商品 ID、去重和错误规则。
- 集成：SQLite schema、约束、种子、事务、Repository。
- Adapter：脱敏 Excel/CSV 正常与异常样本。
- UI 冒烟：启动、选择文件、检查门禁、查询筛选。

## Phase1 验收

1. 三渠道真实脱敏样本均能解析为统一模型。
2. 未知国家、未知档位、坏价格和冲突记录不能进入正式版本。
3. 确认事务失败时无半版本；每渠道最多一个活动版本。
4. 档位视角与国家视角结果与数据库一致。
5. 原文件、摘要、版本、导入时间和记录数可追溯。

## 质量门禁

`pytest` 全部通过；关键解析/校验模块需覆盖正常、边界、异常；无真实敏感数据进入仓库；人工验收记录实际样本版本、预期/实际结果和遗留问题。

## P1-008 计划验收

- Repository/查询服务覆盖活动与历史版本、三渠道独立版本组合、档位/国家视角、排序、筛选和缺价，确保不发生跨版本串数。
- UI 覆盖两种视角、年月分组/折叠/搜索版本选择器、渠道/币种/搜索筛选、重置、刷新、只读详情和各类空状态。
- 验证所有表头、价格和缺价符号居中，币种紧跟价格；Decimal 展示不换算、不额外取整、不使用科学计数法或千位分隔符。
- 使用临时数据库建立三渠道活动/历史版本，不向正式数据库写测试价格；P1-008 全流程不得写正式价格或改变版本状态。
- 详细验收以 `docs/03_开发设计/19_P1-008价格库查询执行说明.md` 为准；当前规则已确认但尚未开始开发。
