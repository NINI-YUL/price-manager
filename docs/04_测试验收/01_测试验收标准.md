# 测试验收标准

## 测试层级

- 单元：金额、编码、表头、商品 ID、去重和错误规则。
- 集成：SQLite schema、约束、种子、事务、Repository。
- Adapter：脱敏 Excel 正常/异常样本。
- UI 冒烟：启动、选择文件、检查门禁、查询筛选。

## Phase1 验收

1. 三渠道真实脱敏样本均能解析为统一模型。
2. 未知国家、未知档位、坏价格和冲突记录不能进入正式版本。
3. 确认事务失败时无半版本；每渠道最多一个活动版本。
4. 档位视角与国家视角结果与数据库一致。
5. 原文件、摘要、版本、导入时间和记录数可追溯。

## 质量门禁

`pytest` 全部通过；关键解析/校验模块需覆盖正常、边界、异常；无真实敏感数据进入仓库；人工验收记录实际样本版本、预期/实际结果和遗留问题。

## 文档验收

任务完成后同步项目状态、更新记录、决策变化和对应执行说明。未确认的假设必须显式列出，不得伪装成已验收规则。
