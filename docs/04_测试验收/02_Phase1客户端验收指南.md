# Phase1 客户端验收指南

版本：V1.3｜日期：2026-08-19｜最终结论：通过

## 一、启动方式

在项目根目录双击：

`启动Phase1验收环境.cmd`

成功后会打开 Windows 桌面客户端，窗口标题包含“Phase1 独立验收环境”。客户端提供三个主入口：

- 价格导入
- 价格库
- 版本管理

验收不是通过命令行操作。启动脚本只负责打开客户端。

## 二、数据隔离

验收环境固定使用：

```text
acceptance_runtime/
├── data/price_manager.db
├── archives/
└── exports/
```

正式环境继续使用根目录的 `data/`、`archives/` 和 `exports/`。两套数据库和归档目录完全分离，验收确认入库、版本切换和来源归档都不会写入正式环境。

`acceptance_runtime/` 已加入 Git 忽略，不会提交到 GitHub。

## 三、建议验收顺序

### 1. 基础界面

- 窗口标题明确显示“Phase1 独立验收环境”。
- 左侧固定导航可切换“价格导入”“价格库”“版本管理”。
- 客户端无异常退出、页面空白或控件重叠。

### 1.1 客户端验收整改检查

- 导入检查左侧标题为“解析详情”，右侧标题为“解析问题（错误/警告）”，默认约 70:30，可拖动分隔条。
- 解析详情最左侧显示从 1 开始的连续行号，同时显示国家码和国家/地区中文名；筛选后行号按当前结果重新连续编号；iOS 调价方式显示“手动调价/自动调价”。
- 无错误或警告时，右侧显示“本次解析无异常”；问题说明为中文并保留代码和来源位置。
- 本地价格整数显示整数，非整数显示两位；若出现超过两位有效小数则保留原值并提示核对。
- 使用真实 Google/iOS 样本切换国家和 14 个档位，界面应保持响应，不应出现分钟级“未响应”。

归档根目录本轮不可在客户端更换。若人工删除某个归档文件，数据库中的价格版本仍保留，但版本管理的归档校验会显示来源缺失；请勿把手工删除作为正常清理方式。

### 2. Google 导入

选择：`D:\Desktop\google-product\google价格_get_result.xlsx`

预期摘要：

- 2,422 条价格
- 173 个国家/地区
- 61 种币种
- 14 个档位
- 无阻断问题

确认入库后应生成 Google ACTIVE 版本并完成来源归档。

### 3. iOS 导入

选择目录：`D:\Desktop\ios价格0817`

预期摘要：

- 2,450 条价格
- 175 个国家/地区
- 43 种币种
- 14 个档位
- N/手动 364 条
- Y/自动 2,086 条
- 无阻断问题

确认入库后应生成 iOS ACTIVE 版本和 ZIP 来源归档。

### 4. 三方网页导入

选择：`D:\ChromeDownload\标准价格配置表 (1).xlsx`

预期摘要：

- 420 条价格
- 30 个国家/地区
- 20 种币种
- 14 个档位
- 无阻断问题

黄色填充、收入列和颜色样式不应参与业务判断。确认后应生成 Web ACTIVE 版本并归档原文件。

### 5. 价格库

- 三个渠道各自默认选择 ACTIVE 版本。
- 可切换档位视角与国家视角。
- 渠道版本选择互不影响，历史版本按年月分组并可搜索。
- 标题与价格居中，币种跟随价格显示。
- 缺价显示 `—`，不从其他版本补值。
- 详情只读，不提供改价、删除或导出。

### 6. 版本管理

- 可按渠道、状态、年月和关键字筛选。
- 可查看版本统计、来源归档、关联任务和状态记录。
- “在价格库查看”只切换目标渠道，其他渠道保持不变。
- 有同渠道两个不同版本时，可验收历史版本重新启用：必须勾选确认，当前 ACTIVE 与目标 ARCHIVED 原子互换，并产生状态审计。
- 页面不提供删除版本、单独归档当前 ACTIVE 或价格导出。

若暂时只有一个来源版本，同渠道历史启用场景可保留到取得第二份真实价格文件后验收；该事务和回滚路径已有自动化测试覆盖。
