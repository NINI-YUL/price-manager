# AI 开发上下文说明

这是“多渠道本地化价格管理工具”，面向非开发背景的价格运营人员。当前已完成 Phase1 三渠道价格管理与 Phase2 只读汇率偏差分析。

## 固定上下文

- Windows 本地桌面；Python、PySide6、SQLite、openpyxl。
- Adapter 隔离渠道差异；页面不直接解析 Excel。
- 正式价格必须经过检查和用户确认。
- 金额使用 Decimal；国家/币种使用标准编码。
- Phase1 于 2026-08-19、Phase2 于 2026-08-21 正式通过客户端验收；代码数据库基线为 schema v5，当前 158 项测试、Ruff 与双客户端 Qt 冒烟通过。Phase3、价格导出及其他范围尚未授权。
