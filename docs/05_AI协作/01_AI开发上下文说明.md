# AI 开发上下文说明

这是“多渠道本地化价格管理工具”，面向非开发背景的价格运营人员。当前只执行 Phase1：三渠道文件导入、统一价格库、检查和版本留存。

## 固定上下文

- Windows 本地桌面；Python、PySide6、SQLite、openpyxl。
- Adapter 隔离渠道差异；页面不直接解析 Excel。
- 正式价格必须经过检查和用户确认。
- 金额使用 Decimal；国家/币种使用标准编码。
- P1-001～P1-007 已完成；schema v3、统一检查页、确认事务和来源归档已验收。当前下一开发入口为 P1-008 价格库页面，必须先确认查询视角、筛选、空状态与导出边界。
