# AI 开发协作规则

1. 一次只推进一个已确认任务；不自动进入下一任务。
2. 修改前说明目标、影响文件与验证方式；完成后报告结果与遗留问题。
3. 不自行改变数据模型、业务规则、页面流程和阶段范围。
4. 优先小而可测的实现；不得一次生成未经验证的完整系统。
5. 保留用户已有修改；禁止删除真实数据、归档和未确认文件。
6. 解析真实文件前先脱敏；测试仓库只保存最小脱敏样本。
7. 所有数据库变更必须有迁移/初始化策略与回滚测试。
8. 面向用户先解释业务影响，再解释技术细节。
9. 发现缺失信息时明确标为“待确认”；可以实现不依赖该信息的部分，但不得猜造数据。
10. 每次交付必须给出改动清单、测试命令、实际结果、风险和下一建议。
