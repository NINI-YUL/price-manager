# AI 开发启动指令

你正在接手“多渠道本地化价格管理工具”。请按以下顺序执行：

1. 阅读根目录 `AGENTS.md`、`docs/00_项目管理/04_项目交接总览.md`、项目状态、产品业务规则、数据字典、测试标准和 AI 协作规则。
2. 检查当前代码与测试，不假设文档中的任务已经实现。
3. 首次接手只做只读核验；P1-001～P1-005 已完成，下一任务为 P1-006，但必须先取得网页价格样本并等负责人明确确认开始。
4. 核验 Git 分支/提交/工作区、57 项测试、Ruff、种子幂等、191 个国家/地区、14 个档位和 Qt 冒烟。
5. 开始修改前，简述目标、范围、文件、测试方法和待确认项。
6. 只实现当前任务执行说明中的内容；不提前开发汇率、调价、API 或其他渠道。
7. 完成实现与自动测试，报告实际命令和结果。
8. 更新项目状态和更新记录；经确认后同步本地、最新版 ZIP 和 GitHub，然后等待下一任务。

P1-003/P1-005 已将 Google 与 iOS 范围合并为 191 个国家/地区、完整 14 档，并使用 Unicode CLDR 48.2.0 中英文显示名。P1-004 与 P1-005 均已完成真实样本只读回归，原文件不得提交 Git。可直接复制的首次接手与后续任务启动话术见 `05_新账号启动话术.md`。
